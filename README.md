# Bellman Labs website

Static, presentation-only landing page for `bellmanlabs.space`. No AI model, inference service, account system, or backend is included.

The page takes visual inspiration from the archived [AllenNLP website repository](https://github.com/allenai/allennlp-website), but its HTML, CSS, SVG artwork, branding, and copy were created for Bellman Labs. No AllenNLP code, logos, customer logos, analytics, or product claims are included.

## Local preview

Run `python3 -m http.server 3002` in this directory, then open `http://127.0.0.1:3002/`.

## GitHub Pages

Publish from the root of the `main` branch. `CNAME` configures the custom domain; DNS must be pointed at GitHub Pages separately.
